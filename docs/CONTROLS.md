# Controls

## Movement

- Move left/right: A / D or Left / Right
- Jump: Space
- Drop through platform: S or Down + Space

## Combat and Item Use

- Use held item / attack: Left mouse button
- Select hotbar slot: 1 to 0

## UI Toggles

- Inventory: Tab
- Crafting panel: C
- Debug ImGui: F10

## World Utility Binds

- Save world: Ctrl + S
- Load world: Ctrl + L
- Spawn Eye boss (debug): F9

## Notes

- Crafting availability depends on nearby station requirements.
- Hotbar switching can be delayed while active use timers are running.
