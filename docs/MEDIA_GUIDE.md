# Media Capture Guide

This guide defines the expected media assets for README placeholders and CV-ready repository presentation.

## Naming Convention

Store media in docs/media using the exact filenames below:

1. 01-gameplay-overview.gif
2. 02-world-generation.png
3. 03-inventory-crafting.png
4. 04-combat-encounter.gif
5. 05-boss-encounter.gif
6. 06-day.png
7. 07-night.png
8. 08-texture-default.png
9. 09-texture-hd.png
10. 10-architecture-demo.mp4

## Capture Checklist

### 1) Gameplay Overview GIF

- Duration: 10 to 20 seconds
- Include: movement, mining, and one combat interaction
- Goal: show the core loop quickly

### 2) World Generation Screenshot

- Single wide frame
- Include biome transition, cave entrances, and elevation variation
- Goal: show procedural map identity

### 3) Inventory and Crafting Screenshot

- Inventory panel open
- Crafting panel open
- Hover one recipe item if possible
- Goal: show usability and systems depth

### 4) Combat Encounter GIF

- Duration: 6 to 12 seconds
- Include hit feedback and enemy reaction
- Goal: show combat readability and pacing

### 5) Boss Encounter GIF

- Duration: 8 to 15 seconds
- Include movement pattern and at least one phase transition or summon moment
- Goal: show advanced enemy behavior

### 6) Day/Night Comparison Pair

- Capture same location and camera framing
- One image in day state, one in night state
- Goal: show environmental mood shift and readability

### 7) Texture Pack Comparison Pair

- Capture same location with default textures and HD textures
- Goal: show art pipeline flexibility

### 8) Architecture/Debug Clip (optional)

- Short MP4 clip
- Show debug panel and one or two runtime toggles
- Goal: support professional engineering presentation

## Quality Recommendations

- Resolution: 1280x720 minimum (1920x1080 preferred)
- Keep HUD visible for gameplay clips
- Avoid heavy compression artifacts in GIFs
- Use consistent capture scene when comparing variants

## Suggested Capture Order

1. Gameplay overview
2. Inventory/crafting
3. Combat
4. Boss
5. Day/night pair
6. Texture pack pair
7. Optional architecture clip
