# Roadmap

## Near-Term (Active)

1. Attack style completion
- Implement THRUST and CAST behavior paths.
- Add hit logic and gameplay integration for those styles.

2. Content expansion based on todo goals
- Add chests and chest interactions.
- Add guns and bullets.

3. Combat and systems extensions
- Implement entity factions so same-faction projectiles do not cause friendly damage.
- Add buffs/debuffs and status-effect foundation.

4. World interaction upgrades
- Add hammer slope logic for stair-style block shaping.
- Add torches as craftable placeable light sources.

5. Enemy pressure improvements
- Improve enemy spawn behavior and pacing around the player.
- Expand enemy roster (for example caster-style enemies with projectile attacks).

## Mid-Term

1. Expanded progression content
- More item branches across materials, tools, and utility builds.
- Additional crafting stations/recipes where needed.

2. Boss and encounter growth
- Expand boss lineup and improve boss reward design.
- Build stronger encounter variety across depth/biome.

3. Combat feel upgrades
- Additional weapon hit effects and moment-to-moment combat feedback.

4. Engine/UI improvements
- Continue renderer and UI quality-of-life improvements when they directly support gameplay.

## Long-Term

1. Swing polish
- Improve animation feel and timing further after feature-complete combat styles.

2. Lighting pass
- Revisit night readability and atmosphere tuning.
- Evaluate full-screen darkness composition path and final artistic direction.

3. Save/load hardening
- Broader edge-case validation and long-session reliability checks.

4. Gameplay loop tightening
- Structured progression pass for clearer goals and pacing.

5. Release quality
- Packaging, balancing, and final stability checklist for external players.
