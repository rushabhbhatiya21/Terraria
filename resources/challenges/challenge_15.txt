So I showed you how to implement the transition for the backgrounds. Implement something similar for the music. So each biome should have its own music, and as you change the biome, the music should slowly transition into the new one. For this, you will need 2 Music objects, and call the updateMusicStream for each. So you will basically have int currentMusicPlaying = 0; an int currentMusicFadingOut = 0; and a timer. Af you change the music, the currentMusicFading out becomes the old music, the new music is set to currentMusicPlaying, and using the timer, you slowly fade the volume of the fading music to 0, and fade up the currentMusicPlaying volume.
